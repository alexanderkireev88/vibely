# Vibely

Публичная русскоязычная социальная платформа. В репозитории теперь есть frontend MVP с подключаемым Supabase backend: регистрация/вход, профили, общая лента, публикации текста и одного фото/видео, лайки, комментарии, realtime-обновления и базовая защищённая панель владельца.

## Запуск настоящего backend

В текущем окружении нет доступа к вашему проекту Supabase и секретам хостинга. Поэтому база не развёрнута автоматически и сайт пока не подключён к живому backend. Для включения функций нужен бесплатный проект Supabase (позже объём медиа может потребовать платный тариф):

1. Создайте проект на [supabase.com](https://supabase.com/) и дождитесь завершения настройки.
2. В **SQL Editor** вставьте и выполн��те `supabase/schema.sql`.
3. В **Project Settings → API** скопируйте Project URL и **publishable/anon key**. Это клиентский публичный ключ, его можно использовать в браузере только вместе с RLS-политиками из schema.
4. В `supabase-config.js` замените `YOUR_PROJECT_ID` и `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY` на значения вашего проекта.
5. В **Authentication → URL Configuration** добавьте адрес публикации сайта в Site URL и Redirect URLs. Для локального теста добавьте `http://localhost:8000/**`.
6. Для владельца: зарегистрируйте свой аккаунт в приложении, затем в SQL Editor выполните запрос, подставив свой email:

```sql
update public.profiles p
set role = 'owner'
from auth.users u
where p.id = u.id and u.email = 'ВАШ_EMAIL';
```

7. Локально запустите `python3 -m http.server 8000` и откройте `http://localhost:8000`.

## Публикация сайта

Frontend — статический сайт, его можно опубликовать на GitHub Pages, Netlify или Vercel. Для GitHub Pages в репозит��рии откройте **Settings → Pages → Deploy from a branch**, выберите `main` и `/ (root)`. После публикации добавьте созданный адрес в Supabase Auth URL Configuration. GitHub Pages сам не создаёт базу или хранилище; backend — отдельный Supabase проект.

## Функциональность и ограничения MVP

- Настоящая регистрация и вход через Supabase Auth; пароль не хранится приложением.
- Публичные профили, общая лента, загрузка одного медиафайла к посту, лайки и комментарии.
- Фото/видео сохраняются в Supabase Storage; настроены ограничения MIME/размера и RLS на загрузку в личный каталог пользователя.
- Realtime обновляет ленту при новых постах, лайках и комментариях.
- Панель владельца доступна только аккаунтам с ролью `owner` или `admin`.
- Видеозвонки, приватные сообщения, жалобы/модерация и мобильные push-уведомления пока не входят в MVP. Они требуют отдельной разработки и настройки сервисов. Не публикуйте приватные или незаконно полученные материалы.

**Не помещайте service_role key или другие секреты в браузер/репозиторий.** `supabase-config.js` содержит только публичные клиентские значения. Храните учётные данные Supabase в защищённом месте; перед широким запуском настройте подтверждение почты, CAPTCHA/rate limits, резервное копирование, правила хранения и модерацию контента.
