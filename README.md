# Vibely

Vibely — адаптивная русскоязычная демо-основа социальной платформы. Репозиторий сейчас содержит первый **работающий интерфейс**: ленту, поиск, демо-истории, папки, создание постов с локальными фото/видео, лайки, сохранение, комментарии к собственным постам и мобильную навигацию.

## Посмотреть локально

Откройте `index.html` в браузере или запустите любой статический сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Опубликовать на GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Дождитесь окончания публикации. GitHub покажет ссылку на сайт в разделе Pages.

## Важно: это пока только демо-интерфейс

Сейчас нет серверной базы данных, регистрации и входа, синхронизации между устройствами, настоящих историй, личных сообщений, звонков, модерации или панели администратора. Созданные посты и папки сохраняются только в `localStorage` этого браузера; выбранные файлы доступны локально и не загружаются на сервер. Демо-публикации и фотографии рекомендаций — примеры.

**Не вводите реальные пароли и не загружайте личные данные.** `localStorage` не подходит для хранения секретов или построения публичной социальной сети. Для следующего этапа потребуется подключить серверную авторизацию, базу данных и объектное хранилище с проверкой доступа, лимитами загрузки и модерацией. Владелец репозитория должен самостоятельно создать и настроить ключи/проекты хостинга; секретные ключи нельзя помещать в публичный репозиторий.

## Структура

- `index.html` — разметка и интерфейс
- `styles.css` — адаптивные стили
- `app.js` — клиентские интерактивные функции и демонстрационные данные
