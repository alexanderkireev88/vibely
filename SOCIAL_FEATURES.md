# Следующий этап: подписки и личные сообщения

Для добавления приватных сообщений к уже настроенной базе выполни `supabase/messaging.sql` в Supabase SQL Editor. Таблица сообщений защищена RLS: читать переписку могут только отправитель и получатель; отправитель может создавать сообщение только от своего аккаунта. Добавь после `app.js` в `index.html`:

```html
<script src="social.js"></script>
```

После подключения появится кнопка «Сообщения»: можно искать публичные профили, подписываться и открывать личную переписку с realtime-обновлением. Для реальной эксплуатации настрой лимиты запросов/защиту от спама, жалобы и блокировки пользователей.
